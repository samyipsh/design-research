Object storage timeline, 1998–2026

Companion to the note 02 How S3 Became the Convention. As of 2026-10-18. Each event says what changed and why it matters for a solo web developer, with its source. Badges: primary = the organization or author describing their own work, vendor = a company selling something related, secondary = press or commentary, snippet = seen in search results only.

The four eras at a glance

  • 1998–2005 · IdeasResearch argues servers shouldn't sit on the data path. Clients should get cryptographic permission and talk to storage directly.
  • 2006–2012 · S3 becomes the APIStorage becomes a pay-per-use web service. Browsers gradually learn to upload directly: POST forms, multipart, CORS.
  • 2013–2020 · Hardening and copyingLeaks lead to safer defaults, consistency gets fixed, and rivals adopt the S3 API to inherit its tooling.
  • 2021–2026 · Price wars, exits, wrappersEgress becomes the battleground, big users leave, managed upload services appear, and self-hosting gets shaky.

Events

  1. 1998Research & big tech

    CMU's NASD: take servers off the data path

    The Network-Attached Secure Disks research makes direct client transfer and cryptographically secured interfaces core principles. The aim is to avoid paying for servers whose main job is moving data.

    This is the conceptual root of presigned URLs: a trusted party grants narrow cryptographic permission, and the bytes go directly between client and storage.

    CMU PDL: NASD abstract (ASPLOS VIII)primary

  2. 2006-03-14S3 capabilities

    Amazon S3 launches as pay-as-you-go web storage

    Deliberately few features: SOAP and REST interfaces, objects up to 5 GB, per-object ACLs, $0.15/GB-month stored and $0.20/GB transferred, designed for 99.99% availability. Object storage already existed. S3 made it a web utility.

    A small HTTP API and per-GB pricing meant anyone could build on it. Its core API is what "S3-compatible" services implement today.

    Amazon press releaseprimary · Jeff Barr launch postprimary

  3. 2008S3 capabilities

    Browser uploads via signed HTML POST forms

    Same-origin rules kept page JavaScript from talking to S3 directly, but a plain HTML form carrying a signed policy could upload straight into a bucket.

    This was the first way to keep file bytes off your server, and it's the ancestor of today's presigned POST with its size and type conditions.

    Simon Willison, 2008-06-27secondary

  4. 2010-10Research & big tech

    Facebook's Haystack paper

    Over 260 billion images (20+ PB) and about 1 billion new photos a week. Filesystem metadata cost several disk operations per photo read, so they built a lean object store. Four sizes were stored per photo, and a CDN served the hot images while the "long tail" hit storage.

    It explains why web files belong in object storage, why your DB should hold the meaning, and why you serve resized variants.

    Haystack (OSDI '10, PDF)primary

  5. 2010-11 / 12S3 capabilities

    Multipart upload, then 5 TB objects

    Objects can be uploaded in parallel, retryable parts, and the max size rose from 5 GB to 5 TB. Vogels' example was a 50 GB HD movie.

    This is the basis of large and resumable uploads. You'll want it once files regularly exceed ~100 MB.

    Vogels, 2010-12-09primary

  6. 2012-08-31S3 capabilities

    CORS support: browser JS talks to S3 directly

    JavaScript on your site can now upload to S3 directly, with drag-and-drop and progress bars, without a proxy server in between.

    This made the modern direct-upload pattern possible, and it's why you configure CORS on your bucket.

    Jeff Barr, AWS News Blogprimary

  7. 2014-08Research & big tech

    Facebook's f4: a "warm" storage tier

    Rarely accessed blobs moved to a tier that cut the effective replication factor from 3.6 to 2.8 or 2.1.

    Storage "temperature" tiers matter at huge scale. For a small app they're a later optimization, not a day-one design.

    f4 (OSDI '14)primary

  8. 2016-03Economics & egress

    Dropbox moves most storage off S3

    Press reports said Dropbox, an early S3 adopter, had moved about 90% of its storage onto its own "Magic Pocket" system.

    Leaving S3 is a scale decision (hundreds of PB), not a template for small apps.

    The Registersecondarysnippet

  9. 2017-02-28Safety & reliability

    S3 us-east-1 outage (~4 hours)

    A mistyped command during debugging removed too much capacity, and S3's index and placement subsystems needed full restarts. Even AWS's status dashboard depended on S3.

    Availability and durability are separate. AWS's summary describes an availability failure, not data loss, yet many sites broke. Every storage dependency sits on your critical path.

    AWS service event summaryprimary

  10. 2018-11-15Safety & reliability

    S3 Block Public Access

    Account- and bucket-level switches that override public ACLs and policies, introduced after a series of data exposures through misconfigured buckets.

    "Just make the bucket public" stopped being the easy default. Plan for private buckets.

    AWS What's Newprimarysnippet

  11. 2020-05-04S3-compatible ecosystem

    Backblaze B2 adds S3-compatible APIs

    Launched with partners, pitched as letting existing S3 users point their tools at a new destination.

    Copying S3's API is the cheapest way for a rival to inherit S3's tooling and win switchers.

    Backblaze press release (PDF)vendorsnippet

  12. 2020-12-01S3 capabilities

    Strong read-after-write consistency, for free

    This ended 14 years of eventual consistency, during which big users built workarounds such as Netflix's s3mper and Hadoop's S3Guard.

    "Upload, then immediately HEAD the object" is reliable on S3, which is what your finalize step relies on. It doesn't refresh CDN caches or make DB + bucket updates atomic. Check other providers' guarantees.

    AWS What's Newprimarysnippet · Vogels, 2021primary

  13. 2021-09-28Economics & egress

    Cloudflare announces R2: S3 API, zero egress

    Announced as S3-API-compatible storage with zero egress fees, at $0.015/GB-month at launch.

    Egress became the competitive battleground. For download-heavy apps, a zero-egress provider changes the cost picture.

    Cloudflare blogvendor

  14. 2023-04Safety & reliability

    New S3 buckets: Block Public Access on, ACLs off, by default

    Applied to new buckets however they're created (console, CLI, SDK, CloudFormation).

    Old tutorials that upload with public-read ACLs fail on new buckets. Keep the bucket private: private files go out through short-lived signed URLs, and public files through a CDN with origin access (or a prefix you deliberately make public). A custom domain alone is just a name.

    AWS What's Newprimarysnippet

  15. 2023-04 / 05UploadThing

    UploadThing appears; "bring your own S3" closed as not planned

    npm package first published 2023-04-14, GitHub repo created 2023-05-10. On 2023-05-11 a request to use your own S3-compatible bucket was closed "not planned". The same month, Garret Harp published the counterpoint "Uploads Are Easy".

    From the start, UploadThing was a hosted service rather than a client for your bucket.

    GitHub issue #28primary · Garret Harp, 2023-05-06secondary

  16. 2023-07-27Research & big tech

    Warfield: "Building and operating a pretty big storage system called S3"

    S3 described as a living service on millions of drives. A drive still does only about 120 random operations per second, hence massive spreading of data. Includes durability reviews and formal verification.

    Operating storage is the real work. Let a provider do it, and keep your own integration thin.

    All Things Distributedprimary

  17. 2024-03-05Economics & egress

    AWS waives egress for customers leaving

    Free internet egress when moving data out of AWS (after support approval), on top of the standing 100 GB/month free tier.

    Exit costs are negotiable now, but data gravity remains. Store keys, not provider URLs.

    AWS News Blogprimarysnippet

  18. 2024-04 / 05Economics & egress

    The "empty bucket bill", and AWS's fix

    Strangers' misconfigured tools sent ~100M unauthorized PUTs to a developer's bucket, and AWS billed for the failed requests. AWS then stopped charging for 403s from outside your account or organization (announced 2024-05-13, fully rolled out 2024-08-19).

    Authorized traffic still costs money. Set billing alerts from day one (they warn, they don't cap) and per-user quotas.

    Simon Willisonsecondary · AWS What's Newprimary

  19. 2024-06-11Safety & reliability

    Managed malware scanning for new S3 uploads (GuardDuty)

    Scans each new object in selected buckets and reports or tags the result.

    Worth adding once users share documents with other users.

    AWS What's Newprimarysnippet

  20. 2024-08-20S3 capabilities

    Conditional writes (If-None-Match)

    "Only create if the key doesn't exist" on PutObject and CompleteMultipartUpload.

    Safe retries without accidental overwrites. R2 also evaluates conditional PutObject atomically.

    AWS What's Newprimarysnippet

  21. 2024-09-10UploadThing

    UploadThing's first major outage (53 minutes)

    While moving files off a single "all in one" S3 bucket into regional buckets, a URL-rewrite bug in a Cloudflare KV cache made all hosted file URLs inaccessible. The report says no data was lost.

    A managed service has its own moving parts (cache, CDN domain, buckets) on the read path. Here reads failed while the stored files stayed intact.

    UploadThing incident reportprimary

  22. 2024-09-13UploadThing

    UploadThing v7: its own ingest servers

    The browser now uploads to UploadThing's Ingest Server instead of to S3 via presigned URLs. Polling is gone, resumable uploads arrive, and "bring-your-own-bucket" and transcoding are listed as future work.

    "A wrapper around S3" describes v6. In the documented v7 design, files go through UploadThing's servers into UploadThing-managed storage, not a bucket you configure.

    UploadThing v7 launch postprimary

  23. 2024-10-17Economics & egress

    DHH: ~10 PB in S3 at ~$1.3M a year

    37signals' remaining cloud spend was all S3, locked into a four-year contract from 2021, with an exit planned for summer 2025.

    At petabyte scale owning hardware wins. At your scale, the lesson is just to keep exit possible.

    DHH, HEY Worldprimary

  24. 2024-11-26UploadThing

    Theo's own list of S3 pain points

    Setup complexity, not knowing when a presigned upload finished, unpredictable egress, and large video uploads breaking. He also says plain file streaming from a bucket is a poor video experience.

    The pain points are real glue and operations problems, not "storing bytes is hard". Video needs a separate service either way.

    Mux blog interviewvendor

  25. 2025-01-30UploadThing

    UploadThing usage-based pricing

    $25/month including 250 GB, then $0.08/GB, advertised with no charges for seats, requests or bandwidth.

    Bundled bandwidth is the main economic offer. Service terms weren't reviewed, so check limits before relying on it for heavy traffic.

    UploadThing blogprimary

  26. 2025-05-09Economics & egress

    37signals' S3 exit underway; $250k egress waived

    The data migration was about to start, with the AWS account to be deleted afterwards. (The Register reports 18 PB, which differs from DHH's ~10 PB.)

    The 2024 exit-egress waiver applied in practice, though getting it approved took time.

    The Registersecondary

  27. 2025-08-17UploadThing

    Latest UploadThing SDK release: 7.7.4

    No newer npm release as of 2026-10-18 (the repo was last pushed 2026-09-30). Earlier in 2025: dynamic region selection (7.7.0, 2025-05-09).

    These dates describe the client SDKs, not how actively the hosted service is run.

    npm registryprimary · CHANGELOGprimary

  28. 2025-12-02S3 capabilities

    S3 maximum object size: 50 TB

    A tenfold increase. AWS's limits page lists 48.8 TiB.

    Mostly relevant to video and data workloads. The API keeps growing without breaking.

    AWS What's Newprimarysnippet

  29. 2025-12 → 2026-04S3-compatible ecosystem

    MinIO community edition: maintenance mode, then archived

    Reported maintenance mode in December 2025. The repo (61.3k stars) was archived on 2026-04-25, with a README saying it's unmaintained and pointing to paid products.

    Self-hosted "S3-compatible" depends on someone else's business model, and it makes you the operator.

    MinIO GitHubprimary · InfoQsecondarysnippet

  30. 2026-03-14S3 capabilities

    S3 turns 20

    AWS's own figures: more than 500 trillion objects, more than 200 million requests per second, and storage a little over 2 cents per GB, about 85% cheaper than at launch.

    The convention is more entrenched than ever. Learning S3's model pays off across providers.

    AWS Weekly Roundupprimary

  31. 2026-10-18UploadThing

    Snapshot: UploadThing today

    ~820k npm downloads for 2026-09-17 → 2026-10-16 (about 6x the same window in 2024) and 5,351 GitHub stars. Within Payload CMS's adapter set, its adapter's downloads are ~0.6% of the S3 adapter's. Bring-your-own-bucket, self-hosting and bulk export aren't documented.

    Meaningful, growing distribution. Production adoption at scale isn't established either way. Decide on fit, control and exit, not on the popularity label.

    npm API (fixed window)primary · Payload adaptersprimary · UploadThing docs sitemapprimary
